# Tinsel updates

This repository holds the update feed for [Tinsel for Mac](https://donbytyci.gumroad.com/l/tinselformac).

- `appcast.xml` is the feed the app reads to find new versions.
- Each version's disk image is attached to a release here.

Tinsel checks this feed by itself; there is nothing to download by hand. A license from Gumroad is needed to use the app.
